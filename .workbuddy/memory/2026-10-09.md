## 按一份 code review 修了 6 处结构性问题（cli/）

1. **惰性字段依赖图类型化**（load.ts）：`FieldSpecs = {[K in keyof LazyRom]: {cost, build}}`，
   漏注册/返回类型错现在是编译错误（实测：给 LoadedRom 加字段 → TS2741）。
   每个字段同时声明 `cost: cheap|moderate|expensive`。
2. **成本可观测**：`LoadStats`（WeakMap 挂载，不改 LoadedRom 形状）+ 新全局 flag `--timings`，
   输出每个被读字段的实测耗时和它拖进来的依赖（`joins [declared cheap] <- chapterScans [expensive]`）。
   声明为 cheap 但实测 >100ms 会打 `[declared cheap]`，让 cost 标注能自我纠错。
3. **argv 单实现**（args.ts）：一次 `parseArgs({strict:false, tokens:true, options: 全部flag})`
   - 对 token 做成员检查。`--` 终止符和 `--out -x` 现在走 parseArgs 原生语义。
     ParsedArgv 新增 `resolved`，index.ts 不再重复查命令。
4. **输出契约**：tsconfig include 加 `scripts/**`，两个脚本纳入 typecheck；
   emit-mgba-units.ts 修掉过时的 `dump` 引用、加了 payload shape 校验。
   **重要**：mgba/units.lua 的输入必须来自 `units --all`（249 条），默认只出 62 条名册。
5. **上游对照**（scripts/check-upstream.ts，npm run check）：解析 `ROMFE*.cs` 的赋值
   （带括号深度扫描，因为 lambda 里有 `;`）与 layouts.ts 逐字段比对 + cli/data 27 文件 diff
   - `cli/data/UPSTREAM.txt` 版本戳。实测抓到真 drift：FE8J 的 support_talk_pointer /
     support_attribute_pointer 一直是 0（上游 0x86A50 / 0x284C8），已修正。
6. **小问题**：detect 的 sizeOk=false 现在直接 exit 1（截断 ROM 不再 RangeError 崩溃）；
   `--lang` 校验合并到 `isKnownLanguage`；flags 的 commands/notes 用 `CommandName` 字面量联合
   （实测拼错 → TS2820 并提示 Did you mean），registry 改成 `Record<CommandName, Command>`
   保证漏注册也是编译错误。
